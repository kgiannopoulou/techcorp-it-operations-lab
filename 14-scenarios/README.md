# 14 – Scenarios

**Status:** ⏳ Planned – from Phase 1 (M4); every phase adds at least 5 scenarios

Practical problems I am given (or inject into the lab), investigate and solve – the troubleshooting evidence of this repository. Each one uses the [scenario template](../15-documentation/templates/scenario-template.md) and is listed in `scenario-index.md`.

## Planned contents

| Folder | Example scenarios |
|---|---|
| `hardware/` | Laptop does not charge on the dock; second monitor not detected |
| `networking/` | Desk drop has no link; guest Wi-Fi can reach the internal network |
| `windows/` | Group Policy not applying; corrupted user profile |
| `accounts/` | Account locked out repeatedly; access denied on the Finance share |
| `microsoft-365/` | Mail from an external sender not arriving; OneDrive sync stuck |
| `security/` | User clicked a phishing link; unknown admin sign-in |
| `infrastructure/` | DC replication failure; UPS running on battery |
